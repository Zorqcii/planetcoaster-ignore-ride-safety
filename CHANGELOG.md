# Changelog

## 0.1.0-beta — 2026-10-03

First public beta.

* **Ignore ride safety concerns** option: guests no longer refuse rides as too intense. "Not intense enough", nausea, price, queues and needs still apply.
* **Ignore ride nausea** option: a ride's nausea rating no longer puts guests off it.
* Both options live in Options → Game while a park is loaded, start off on every park load, and restore the original game code when switched off.
* Supports only Planet Coaster build 1.13.3.88540; other builds are refused without changes.
* Tested on Linux with Proton Experimental; Windows not tested.
* Requires ACSE-PlanetCoaster 0.2 (installed separately).
